# Screens & flows

| Screen | Purpose | Requirements |
|---|---|---|
| Home / Dashboard | The landing surface after sign-in; entry point to the primary tasks. | FR-001, FR-002 |
| Save an article from a URL or browser extension | Where a user can save an article from a URL or browser extension. | FR-001 |

## User flows

### First-run onboarding _(FR-001, FR-002)_

1. Arrive at an empty, explanatory first-run state
2. Complete the minimal setup
3. Reach the dashboard ready to act

### Save an article from a URL or browser extension — happy path _(FR-001)_

1. Navigate to the relevant screen
2. Perform: save an article from a URL or browser extension
3. Receive clear confirmation of the outcome

### Full-text search across all saved articles — happy path _(FR-002)_

1. Navigate to the relevant screen
2. Perform: full-text search across all saved articles
3. Receive clear confirmation of the outcome
