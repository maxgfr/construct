# Design principles

- Privacy by default — the UI never surfaces or transmits data the user did not choose to share.
- Perceived performance first — optimistic UI, skeletons over spinners, immediate feedback on every action.
- Accessible to everyone — every flow works with the keyboard and assistive technology, by construction.
- Consistency over novelty — reuse tokens and components before inventing new ones.
- Progressive disclosure — show the essential first; reveal complexity only on demand.

## Content & voice

- Voice & tone: clear, concise and human — plain language over jargon.
- Label actions with the outcome the user gets, not the system operation behind it.
- Error messages state what happened, why, and the next step — never blame the user.
- Empty states teach the first useful action; success states confirm exactly what changed.
